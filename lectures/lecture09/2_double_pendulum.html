Double Pendulum Equations and Numerical Solution

Mathematical Formulation

The double pendulum consists of two point masses connected by massless, rigid rods.

Lagrangian Formulation: A Step-by-Step Approach

The Euler-Lagrange formalism provides a powerful method for deriving equations of motion for complex mechanical systems like the double pendulum. This approach is especially useful when dealing with systems that have constraints or multiple degrees of freedom.

Step 1: Identify Generalized Coordinates

First, we choose a set of independent coordinates that completely describe the system’s configuration. For a double pendulum, we use the angles \(\theta_1\) and \(\theta_2\) measured from the vertical:

  • \(\theta_1\): angle of the first pendulum rod from vertical
  • \(\theta_2\): angle of the second pendulum rod from vertical

Step 2: Construct the Lagrangian

The Lagrangian \(L\) is defined as the difference between kinetic energy \(T\) and potential energy \(V\):

\[L = T - V\]

For the double pendulum:

Kinetic Energy (\(T\)):

  • For mass \(m_1\): \(T_1 = \frac{1}{2}m_1(l_1\dot{\theta}_1)^2\)
  • For mass \(m_2\): We need to account for its total velocity, which comes from both pendulum rods

The position of \(m_2\) in Cartesian coordinates is:

\[x_2 = l_1\sin\theta_1 + l_2\sin\theta_2\] \[y_2 = -l_1\cos\theta_1 - l_2\cos\theta_2\]

Taking time derivatives gives us velocity components, and after some algebra:

\[T_2 = \frac{1}{2}m_2[(l_1\dot{\theta}_1)^2 + (l_2\dot{\theta}_2)^2 + 2l_1l_2\dot{\theta}_1\dot{\theta}_2\cos(\theta_1-\theta_2)]\]

So the total kinetic energy is:

\[T = T_1 + T_2 = \frac{1}{2}m_1(l_1\dot{\theta}_1)^2 + \frac{1}{2}m_2[(l_1\dot{\theta}_1)^2 + (l_2\dot{\theta}_2)^2 + 2l_1l_2\dot{\theta}_1\dot{\theta}_2\cos(\theta_1-\theta_2)]\]

Potential Energy (\(V\)): Taking the zero of potential energy at the pivot point:

\[V = m_1gl_1(1-\cos\theta_1) + m_2g[l_1(1-\cos\theta_1) + l_2(1-\cos\theta_2)]\]

Step 3: Apply the Euler-Lagrange Equations

The Euler-Lagrange equation for each generalized coordinate \(q_i\) is:

\[\frac{d}{dt}\left(\frac{\partial L}{\partial \dot{q}_i}\right) - \frac{\partial L}{\partial q_i} = 0\]

For our system, we apply this equation to both \(\theta_1\) and \(\theta_2\).

For \(\theta_1\):

  1. Calculate \(\frac{\partial L}{\partial \dot{\theta}_1}\): \[\frac{\partial L}{\partial \dot{\theta}_1} = m_1l_1^2\dot{\theta}_1 + m_2l_1^2\dot{\theta}_1 + m_2l_1l_2\dot{\theta}_2\cos(\theta_1-\theta_2)\]

  2. Take the time derivative \(\frac{d}{dt}\left(\frac{\partial L}{\partial \dot{\theta}_1}\right)\): \[\frac{d}{dt}\left(\frac{\partial L}{\partial \dot{\theta}_1}\right) = (m_1+m_2)l_1^2\ddot{\theta}_1 + m_2l_1l_2\ddot{\theta}_2\cos(\theta_1-\theta_2) - m_2l_1l_2\dot{\theta}_2\sin(\theta_1-\theta_2)(\dot{\theta}_1-\dot{\theta}_2)\]

  3. Calculate \(\frac{\partial L}{\partial \theta_1}\): \[\frac{\partial L}{\partial \theta_1} = -m_2l_1l_2\dot{\theta}_1\dot{\theta}_2\sin(\theta_1-\theta_2) - (m_1+m_2)gl_1\sin\theta_1\]

  4. Substitute into the Euler-Lagrange equation and rearrange: \[(m_1+m_2)l_1\ddot{\theta}_1 + m_2l_2\ddot{\theta}_2\cos(\theta_1-\theta_2) + m_2l_2\dot{\theta}_2^2\sin(\theta_1-\theta_2) + (m_1+m_2)g\sin\theta_1 = 0\]

For \(\theta_2\):

Following the same procedure: \[m_2l_2\ddot{\theta}_2 + m_2l_1\ddot{\theta}_1\cos(\theta_1-\theta_2) - m_2l_1\dot{\theta}_1^2\sin(\theta_1-\theta_2) + m_2g\sin\theta_2 = 0\]

Step 4: Physical Interpretation

Each term in these equations has physical significance:

  • Terms with \(\ddot{\theta}\) represent accelerations
  • Terms with \(\dot{\theta}^2\) represent centripetal forces
  • Terms with \(\sin\theta\) represent gravitational torques
  • Terms with \(\cos(\theta_1-\theta_2)\) represent coupling between the two pendulums

These coupled, nonlinear differential equations explain why the double pendulum exhibits chaotic behavior for certain initial conditions, as small changes can lead to dramatically different trajectories over time.

Numerical Solution

# Parameters
m1, m2 = 1.0, 1.0  # masses
l1, l2 = 1.0, 1.0  # lengths
g = 9.81  # gravitational acceleration

# Define the system of ODEs
def double_pendulum(t, y):
    theta1, omega1, theta2, omega2 = y

    # Calculate auxiliary values
    delta = theta2 - theta1
    sin_delta = np.sin(delta)
    cos_delta = np.cos(delta)

    # Calculate denominators
    den1 = (m1 + m2) * l1 - m2 * l1 * cos_delta**2
    den2 = (l2 / l1) * den1

    # Avoid division by zero
    den1 = np.where(np.abs(den1) < 1e-10, 1e-10 * np.sign(den1), den1)
    den2 = np.where(np.abs(den2) < 1e-10, 1e-10 * np.sign(den2), den2)

    # Calculate derivatives
    theta1_dot = omega1

    # More accurate equation for omega1_dot
    omega1_dot = (m2 * l1 * omega1**2 * sin_delta * cos_delta
                  + m2 * g * np.sin(theta2) * cos_delta
                  + m2 * l2 * omega2**2 * sin_delta
                  - (m1 + m2) * g * np.sin(theta1)) / den1

    theta2_dot = omega2

    # More accurate equation for omega2_dot
    omega2_dot = (-m2 * l2 * omega2**2 * sin_delta * cos_delta
                  + (m1 + m2) * g * np.sin(theta1) * cos_delta
                  - (m1 + m2) * l1 * omega1**2 * sin_delta
                  - (m1 + m2) * g * np.sin(theta2)) / den2

    return [theta1_dot, omega1_dot, theta2_dot, omega2_dot]

# Initial conditions [theta1, omega1, theta2, omega2]
y0 = [np.pi/4, 0, np.pi/2, 0]

# Time span
t_span = (0, 40)
t_eval = np.linspace(t_span[0], t_span[1], 1000)

# Solve the system using solve_ivp with tighter tolerances for better energy conservation
solution = solve_ivp(double_pendulum, t_span, y0, method='RK45',
                    t_eval=t_eval, rtol=1e-8, atol=1e-8)

# Extract solutions
t = solution.t
theta1 = solution.y[0]
omega1 = solution.y[1]
theta2 = solution.y[2]
omega2 = solution.y[3]

# Convert to Cartesian coordinates for visualization
x1 = l1 * np.sin(theta1)
y1 = -l1 * np.cos(theta1)
x2 = x1 + l2 * np.sin(theta2)
y2 = y1 - l2 * np.cos(theta2)

# Plot the results
plt.figure(figsize=get_size(18, 18))

# Plot angular positions
plt.subplot(2, 2, 1)
plt.plot(t, theta1, 'b-', label='θ₁')
plt.plot(t, theta2, 'r-', label='θ₂')
plt.xlabel('Time (s)')
plt.ylabel('Angle (rad)')
plt.legend()
#plt.title('Angular Positions')
plt.grid(True)

# Plot the trajectory of the second pendulum
plt.subplot(2, 2, 2)
plt.plot(x2, y2, 'r-', label='Path of m₂')
plt.plot(0, 0, 'ko', label='Origin')
plt.axis('equal')
plt.xlabel('x position')
plt.ylabel('y position')
#plt.legend()
plt.grid(True)

# Improved energy calculation
# First, compute velocities correctly
v1x = l1 * omega1 * np.cos(theta1)
v1y = l1 * omega1 * np.sin(theta1)
v2x = v1x + l2 * omega2 * np.cos(theta2)
v2y = v1y + l2 * omega2 * np.sin(theta2)

# Calculate potential and kinetic energy
PE1 = m1 * g * (y1 + l1)  # Potential energy of first mass
PE2 = m2 * g * (y2 + l1 + l2)  # Potential energy of second mass
KE1 = 0.5 * m1 * (v1x**2 + v1y**2)  # Kinetic energy of first mass
KE2 = 0.5 * m2 * (v2x**2 + v2y**2)  # Kinetic energy of second mass

total_energy = PE1 + PE2 + KE1 + KE2
potential_energy = PE1 + PE2
kinetic_energy = KE1 + KE2

plt.subplot(2, 2, 3)
plt.plot(t, potential_energy, 'g-', label='Potential Energy')
plt.plot(t, kinetic_energy, 'b-', label='Kinetic Energy')
plt.plot(t, total_energy, 'r-', label='Total Energy')
plt.xlabel('Time (s)')
plt.ylabel('Energy (J)')
#plt.legend()
plt.grid(True)

# Plot the final state of the pendulum
plt.subplot(2, 2, 4)
plt.plot([0, x1[-1]], [0, y1[-1]], 'k-', lw=2)
plt.plot([x1[-1], x2[-1]], [y1[-1], y2[-1]], 'k-', lw=2)
plt.plot(0, 0, 'ko', markersize=8)
plt.plot(x1[-1], y1[-1], 'bo', markersize=8, label='m₁')
plt.plot(x2[-1], y2[-1], 'ro', markersize=8, label='m₂')
plt.axis('equal')
plt.xlabel('x position')
plt.ylabel('y position')
#plt.legend()
plt.grid(True)

plt.tight_layout()
plt.show()
